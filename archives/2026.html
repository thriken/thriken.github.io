py2htmlblog：把 Markdown 变成博客，就这么简单

py2htmlblog：把 Markdown 变成博客，就这么简单 这是什么 py2htmlblog 是一个 Python 写的静态博客生成器。给它 Markdown 文章、分类信息和一个 HTML 模板，它就能生成一个完整的静态网站，丢到任何地方都能跑——GitHub Pages、虚拟主机、对象存储，甚至 U 盘。 它模仿了老牌博客工具 ThingamaBlog 的设计理念（模板 + 数据 = 静态页面），但用 Python 重写，去掉了对 Java 的依赖，并加入了现代博客需要的所有功能。 能做什么 写文章：用 Markdown 写，带 frontmatter 元数据。
